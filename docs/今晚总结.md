## 明确做不到的（别再试，都有实测证据）

| 想做的事 | 为什么不行 |
|---|---|
| **给 agent 一个 shell / bash** | 鸿蒙**禁止应用启动任何外部程序**：`/bin/sh` 存在但 `spawnSync` 返回 **EACCES** ✗ |
| **`workflow` 多智能体脚本** | 它必须启动子 Node 进程 ⇒ 撞同一道墙 ✗（**替代**：`subagent` ✓）|
| **让 agent 读你手机任意位置** | 沙箱不允许 ✗。实测申请"用户目录读写"权限：**这台设备直接不支持**（返回"不受支持"/801/EPERM）⇒ **唯一合法通道就是那个文件选择器** ✓ |
| **无限后台常驻** | 普通应用做不到：`TASK_KEEPING` 报 9800005（本机不支持）、`DATA_TRANSFER` 报 9900002（进后台后不许再申请）⇒ **最可靠的是让它留在前台** ✓ |
| **选文件夹（递归导入）** | 系统选择器的文件夹模式与自动化不兼容 ✗ ⇒ **优先用文件导入（可靠 ✓）** |

# 使用说明 · DSH for HarmonyOS

> 面向使用者（你），不是开发者。开发者请看 [README.md](../README.md)。
> 当前状态：**可用** ✓（2026-10-08 实测）

---

## 一、它是什么

**真正的 DeepSeek Harness 跑在你的手机里**（不是遥控、不是投屏）。
手机 App 内置了一个完整的 **Node.js v24.2.0** 运行时 + DSH 本体，
界面就是 DSH 自己的 Web UI，由**手机自己**提供服务（`http://127.0.0.1:3080`）。

**⇒ 断网也能打开界面** ✓（只有真正向模型提问时才需要网络 ✓）

---

## 二、三步开始用

1. **打开 App**（桌面图标：深蓝底 + 蓝色终端框）
   顶部状态条出现 **「已就绪」** 即表示端上 Node 与 DSH 都起来了
   （若显示「Node 已退出」⇒ 见第五节）

2. **选一个工作区**（★ 只要选一次，之后 App 会记住）

   **第一次用**（界面上还没有 `workspace` 这一行时）：
   点左侧 **「添加工作区」** → 弹出「选择工作区目录」窗口 →
   点 **`workspace`** 这一行 → 点右下角 **「打开」** ✓

   **以后**（界面上已经有 `workspace` 这一行了）：
   **直接点那一行 `workspace`** 即可立刻选中 ✓（它就在「选择工作区」几个字的正下方）

   **选中的判据**：界面**从"空状态"切换成对话界面** ——
   输入框明显上移，并出现 **「选择模型，当前 DeepSeek-V41-Flash，推理等级 High」** ✓

   > ⚠ 点「选择工作区」这几个字本身**没有反应** ✗（它只是个标签）；
   > ⚠ 也别用系统返回键 ✗ —— 它只会关掉窗口，**不确认选择**。
3. **直接对话**
   在底部输入框写你要做的事，按发送箭头。

## 三、怎么把手机里的文件交给它

**点顶部「导入手机文件夹」按钮** → 系统文件选择器弹出 →
**选文件**（可多选）→ 它们会被**复制**进 App 的沙箱工作区（`workspace/imported/`）

**⇒ 它接下来就能读、解包、分析这些文件** ✓
**实测**：导入了一个 **149 MB 的手机日志 zip**，agent 自己用工具读出其内部结构
（`memory_leak/` `kernel/` `eventlog/` `bt/` …）并给出点评 ✓

> ⚠ **只复制，不动原件** —— App 不会修改或删除你手机里的任何原始文件 ✓
> ⚠ **选文件夹暂不支持**（只能选文件；鸿蒙选择器的文件夹模式与自动化不兼容）✗

## 四、它现在能做什么（实测清单）

**能做的（14 项）**：

| 能力 | 说明 |
|---|---|
| **文件读写** | `read` / `write` / `edit` —— 在工作区内读、写、改文件 |
| **文件查找** | `glob`（按名字找）/ `grep`（按内容搜） |
| **文件管理** ★ | `phone_fs`（本项目自研，13 种操作）：列目录、看详情、建目录、**删除**、**移动**、**复制**、看文件头/尾、统计行数、**解压 zip**、**看目录体积**、**打包成 zip** |
| **联网** | `web_search` 搜索 / `web_fetch` 抓网页 |
| **多智能体** | `subagent` 派子智能体、`subagent_fork` 从当前对话分叉 |
| **任务管理** | `todo_write` 列计划、`job_*` 看后台任务、`list_agents` 看子智能体 |
| **交付** | `present` 把成果文件以卡片形式给你 |

**做不到的（2 项，已确认是系统限制）**：

| 能力 | 为什么 |
|---|---|
| **执行命令行**（`bash`/终端） | 鸿蒙**禁止应用启动任何外部程序**（连系统自带的 sh 都会报 EACCES）⇒ 物理上不可能 ✗ |
| **多智能体工作流脚本**（`workflow`） | 它必须启动一个子 Node 进程 ⇒ 撞同一道墙 ✗（**替代**：用 `subagent` ✓）|

## 五、几个必须知道的注意事项

### 1. 它需要留在前台
鸿蒙会在应用切到后台几分钟后**冻结**它。实测：
- 切后台 90 秒 → **服务直接不可用**（HTTP 000）
- 加了保活后 → 约 **3~4 分钟**内仍可用

⇒ **想看它一直在线，就让屏幕别灭、App 留在前台** ✓
（想省电就在不用时手动退出 ✓）

### 2. 它给不了你手机里"任意位置"的文件
安卓/鸿蒙的沙箱不允许应用随便翻你的文件系统 ✗。
**唯一的合法通道就是那个文件选择器** ✓ —— 你选了什么，它才能看到什么。

> 我试过申请"用户目录读写"权限：**这台设备直接不支持**（运行时返回"不受支持"，
> API 报 801，真实路径报 EPERM）⇒ 此路不通，别在这上面浪费时间。

### 3. 模型与密钥
默认走 DeepSeek 官方接口。**密钥存在 App 私有沙箱里**，不上传任何第三方 ✓
（卸载 App 或系统设置里"清除数据"即全部删除 ✓）

### 4. 你的数据是安全的
- App **只申请 2 个权限**：`INTERNET`（联网提问）+ `KEEP_BACKGROUND_RUNNING`（后台保活）
- **不申请存储权限、不申请相机/麦克风/通讯录**
- 导入 = **复制**；agent 的文件操作被**强制限制在它自己的工作区内**，越界会直接报错 ✓

## 六、出问题怎么办

| 现象 | 原因与处理 |
|---|---|
| 顶部显示 **「Node 已退出」** | 端上 Node 挂过。**杀掉 App 重开**即可（鸿蒙限制：同一进程内 Node 只能启动一次，无法自动重启）|
| **App 一打开就闪退 / 界面起不来** | 大概率是 App 的持久化数据坏了。**卸载重装**即可恢复（实测有效）：<br>`hdc uninstall com.dsh.harmony` + `hdc install -r xxx.hap`。<br>⚠ 注意：卸载会**清空 App 里的会话与导入的文件**（你手机里的原始文件不受影响 ✓）|
| **发了消息但 agent 完全不动** | 多半是**工作区没选中**（界面还显示「选择工作区」）⇒ 按第二节第 2 步：点「选择工作区」→ 弹窗里点 `workspace` → 点**「打开」**（✗ 不是返回键）|
| **报 `no API key for provider route` / `MISSING_CREDENTIAL`** | App 里的凭据丢了（例如刚卸载重装过）。本项目的构建**已内置凭据**（构建时把 `~/.dsh/.credentials.yaml` 放进 `rawfile/credentials.yaml`，该文件被 gitignore、永不入库）⇒ 正常情况下不该出现。<br>若出现：把凭据放到 `harmony/entry/src/main/resources/rawfile/credentials.yaml` 后**重新构建安装**即可 ✓ |
| 界面一直转圈 / 没反应 | 可能被系统冻结了 ⇒ 把 App 切回前台 |
| 「导入手机文件夹」没反应 | 选择器是系统窗口，偶尔会停在"我的云盘"分类 ⇒ 点一下「我的手机」 |
| 提问后很久没回答 | 首次启动要解包 11000 多个文件（约 1~2 秒）；之后主要取决于网络与模型 |

# 隐私声明 · DSH for HarmonyOS（com.dsh.harmony）

> 本声明描述本应用**实际**收集、使用、存储与共享的信息。**与 `module.json5` 中实际申请的权限保持一致**，
> 如代码变更请同步更新本文件（上架审核会逐条核对）。

## 一、本应用是什么

本应用把 **DeepSeek Harness（DSH）** 与 **Node.js v24.2.0** 运行时**打包在本机运行**：
Node 运行时（`libnode.so`）与 DSH 的 JS 载荷（`resources/rawfile/dsh-payload.tar.gz`）
在首次启动时解压到应用**自己的沙箱目录**（`<应用私有目录>/dsh-harmony-data/`），
随后由本机 Node 提供 Web 服务，界面通过应用内的 ArkWeb 组件访问 `http://127.0.0.1:3080`。
**该服务仅监听本机回环地址，不对局域网或互联网开放。**

## 二、申请的权限与用途（仅 2 项）

| 权限 | 用途 | 说明 |
|---|---|---|
| `ohos.permission.INTERNET` | 访问网络 | 仅用于**你主动发起**的模型对话：请求发往你在 DSH 中配置的模型服务（默认 DeepSeek 官方 API）。**不用于上报、统计或广告。** |
| `ohos.permission.KEEP_BACKGROUND_RUNNING` | 后台保活 | 让端上 Node 服务在你切到后台的短时间内继续响应。**不使用定位、麦克风、相机、通讯录、日历等任何其他权限。** |

> 注：本应用**不申请**存储类权限。读取文件一律通过**系统文件选择器**（`@ohos.file.picker`）由你**逐个选定**，
> 系统会把选定内容授权给本应用并复制进应用沙箱；本应用**无法**浏览你手机上的其他文件。

## 三、收集与处理的信息

- **不做任何埋点、统计、画像或广告投放。**
- **对话内容**：仅在你主动发送时，随模型请求发往你在 DSH 中配置的模型服务；本应用不额外留存副本
  （会话记录以文件形式保存在**应用私有沙箱**内，卸载即删）。
- **API 密钥/凭据**：由你自行填写，保存在**应用私有沙箱**的 DSH 配置目录中，**不上传任何第三方**。
- **设备信息**：不收集。
- **崩溃日志**：DSH 的遥测默认配置为 `FEEDBACK_ONLY` —— **只有你主动提交反馈时**才会发送相关会话片段；
  你可通过设置环境变量 `DSH_TELEMETRY_DISABLED` 完全关闭。

## 四、存储与删除

| 数据 | 位置 | 删除方式 |
|---|---|---|
| DSH 会话记录、配置、凭据 | 应用私有沙箱（`files/dsh-harmony-data/`） | 卸载应用，或系统设置中「清除数据」 |
| 你通过选择器导入的文件副本 | 应用私有沙箱（`files/workspace/imported/`） | 同上 |

**本应用不会修改、删除或上传你手机上的任何原始文件**；导入动作只是**复制**。

## 五、第三方

模型推理由**你自行配置的模型服务**提供（默认 DeepSeek 官方 API），其数据处理遵循该服务自身的隐私政策。
本应用不集成任何广告、统计或社交 SDK。
